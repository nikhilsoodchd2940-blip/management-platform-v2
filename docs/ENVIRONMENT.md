# Environment & Secrets Strategy

**No secrets are committed to this repository.** Every `.env.example` / `*.example` file lists required keys with placeholder values only.

## Firebase projects

Three separate Firebase projects, selected via CLI alias, never hard-coded into source:

```bash
firebase use dev        # <app>-dev
firebase use staging     # <app>-staging
firebase use prod        # <app>-prod
```

`.firebaserc` (not committed as real config — `.firebaserc.example` provided) maps these aliases to real project IDs.

## Cloud Functions secrets

Set via Firebase Secret Manager, never in code or `.env` committed to git:

```bash
firebase functions:secrets:set TWILIO_ACCOUNT_SID
firebase functions:secrets:set TWILIO_AUTH_TOKEN
firebase functions:secrets:set TWILIO_VERIFY_SERVICE_SID
firebase functions:secrets:set STRIPE_SECRET_KEY
firebase functions:secrets:set STRIPE_WEBHOOK_SECRET
firebase functions:secrets:set QR_SIGNING_SECRET   # generate with: openssl rand -hex 32
```

`TWILIO_FROM_NUMBER` (Phase 4, reminders) is a regular Functions v2 param, not a secret — it's a public phone number. Set it in a `firebase/functions/.env.<project-id>` file (gitignored) or let the CLI prompt for it on first deploy:

```
TWILIO_FROM_NUMBER=+15557654321
```

Referenced in Functions code via `defineSecret()` (Firebase Functions v2) — see `firebase/functions/src/config/env.ts`.

## Admin web (`admin-web/.env.local`, gitignored)

```
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=       # restricted: HTTP referrer + Places/Geocoding/Maps JS only
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=
NEXT_PUBLIC_RECAPTCHA_SITE_KEY=        # Phase 5 — App Check reCAPTCHA v3 site key; see docs/LAUNCH_CHECKLIST.md
```

Only `NEXT_PUBLIC_*` values ever ship to the browser — this is intentionally the full list; nothing else belongs here.

## Mobile (`mobile/lib/core/firebase_options.dart`, generated per-flavor, gitignored)

Generated by `flutterfire configure` per environment (dev/staging/prod flavors). Google Maps API key (Android/iOS-restricted) supplied via platform-native config (`AndroidManifest.xml` placeholder + `AppDelegate.swift`), not committed with a real value. Stripe's publishable key (safe to ship client-side, unlike the secret key above) is passed at build/run time instead of being committed:

```bash
flutter run --dart-define=STRIPE_PUBLISHABLE_KEY=pk_test_...
```

## What's committed vs. not

| Committed | Not committed |
| --- | --- |
| `*.example` files, `firestore.rules`, `firestore.indexes.json`, `storage.rules`, `firebase.json` | `.env`, `.env.local`, `.firebaserc` (real), `firebase_options.dart` (real), any API key/secret value |

CI (`.github/workflows/ci.yml`) injects secrets from GitHub Actions encrypted secrets at build time — never from a committed file.
